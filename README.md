# 🏋️ PowerLog

PowerLog is a simple, easy-to-use workout tracking app designed to help you stay consistent and always know what your next workout looks like.

## ✨ Features
- **Workout Logging**: Keep track of your daily workouts so you never forget what’s next.  
- **Themes**: Switch between **light** and **dark** mode for a comfortable reading experience.  
- **History Page**: View your **personal records** — the heaviest weight you’ve lifted for each exercise.  

## 🚀 Future Plans
- Add support for **more exercise names**.  
- Ability to **delete workouts entirely**.  

## 🎯 Why PowerLog?
I built PowerLog because I wanted a clean, easy-to-read way to track my workouts, remember my progress, and stay motivated with my personal records.
